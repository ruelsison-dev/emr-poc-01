# Patient Administration — Express API (Scaffold)

This is a minimal scaffold for the Patient Administration REST API using Express + TypeScript.

Run locally:

- npm install
- cp .env.example .env
- npm run dev

Run tests:

- npm test

Notes:
- This scaffold uses in-memory stores for early tests. Integrate Prisma/DB in Phase 1 and implement migrations.
- Add Snyk/npm audit, DAST, and Pact contract tests to CI before production deployment.
